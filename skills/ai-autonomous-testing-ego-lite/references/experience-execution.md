# 执行观察与异常经验

执行方法可自主选择，实际授权、固定条件和验收标准不可替换。

<a id="e-permission"></a>

## 核验实际身份与范围

适用阶段：执行。

核对实际身份、租户、对象归属及授权目标。分别观察入口、操作和业务结果，结论只覆盖真正验证的层次。

不适用与边界：登录成功或 Space 名不是角色证据；看不到按钮不证明后端授权，不能换管理员绕过原目标。

具体场景（合成）：验证只读成员无删除入口，但身份与对象项目不明确。先从已有且获授权的渠道确认账号、角色、租户、对象归属，再观察目标页面。

候选观察与判断：无入口只支持对应 UI 目标；若明确规则禁止展示而入口出现，可以记录 UI 违反，不必继续删除来证明。不能由 UI 隐藏推出服务端拒绝，也不切管理员替代原目标。

子场景：执行中登录过期、角色或租户变化。保存时跳到登录页，先保留中断前事实与可能的写入，恢复后重新核验身份、租户、对象和副作用；不从原点击位置机械续跑。只暂停依赖身份缺口的目标，资源恢复按资源指南处理。

子场景：功能尚未部署、开关关闭或环境版本不符。入口缺失时核对可获知的环境、版本、开关和发布目标，不自动改配置。功能行为测试的前提不满足可能受阻；若目标就是部署或开关验收，不符合明确要求本身可构成发现，不能一律排除为环境问题。

<a id="e-unknown-submit"></a>

## 提交未知与重复操作

适用阶段：执行。

先保留首次现象，利用授权内的安全观察核对同一对象是否已产生副作用，再决定等待、继续观察或说明未知。实际可用接口数据可辅助，不假定已有监控工具。

不适用与边界：没有重复提交契约或结果证据时不要反复点击；数据已保存不能抹掉不符合要求的 UI 反馈。

具体场景（合成）：新建提交后超时，列表未刷新。保留首次画面、回执及本次任务号或稳定业务标识，通过授权内的安全渠道核对结果。查到同名对象不够，要排除旧对象、他人创建和旧任务。

候选观察与判断：可关联本次操作的对象或任务结果能支持副作用已生效；列表暂时未见不能证明未生效。暂停可能重复产生该副作用的相关写入，独立已授权目标仍可继续。是否重试结合明确的幂等契约、任务/取消状态、结果证据与原授权，不写成所有系统通用的禁令。保存成功也不抵消不符合需求的 UI 反馈。

子场景：暂停、浏览器重启或调用失联后的续接。上传失联后将旧回执和当前处理状态对齐，区分已完成、未完成和未知动作，不按计划从头重放；无法恢复证据时说明未知，不虚构中断期间发生的行为。

<a id="e-async"></a>

## 异步与状态观察

适用阶段：执行。

区分请求受理、中间状态和业务完成，按已知时限与可观察信号选择等待和复查；记录观察时点及范围。

不适用与边界：没有时限依据不自设三秒失败；等待不无限继续，停止时说明未完成观察而不是猜通过。

具体场景（合成）：导出显示“已受理”，文件尚未生成。保留任务标识、状态与观察时刻，按明确时限及可观察完成信号选择复查，不用固定等待秒数代替判断。

候选观察与判断：受理仅证明接收；业务完成还需对应任务的最终状态和文件结果。超过明确时限可判断该时效目标是否违反，后续完成不能抹掉超时；无时限依据时说明观察窗口与未确定结果。不适用例：不能无限等待，也不能自定三秒便宣称产品失败。

<a id="e-input"></a>

## 输入方式与边界

适用阶段：执行。

核对实际输入、控件转换和提交后结果是否对应原样本。必要时区分键入、粘贴等操作语义并保留要求。

不适用与边界：不要把控件自动修正后的值当原边界样本已测试；不得暗改固定输入以得到成功。

具体场景（合成）：原目标是超长输入提交后的拒绝，粘贴 21 个字符却被控件截成 20 个。分别记录原样本、控件实际值和授权范围内可观察的提交内容。

候选观察与判断：依据需求评价截断行为本身；这次未证明“21 个字符提交后被拒绝”。不得改成合法值保存后判原检查通过，也不得为提交超长值擅自绕过 UI 或调用接口。不适用例：不同 Unicode 长度口径、粘贴与键入语义需按原目标分析，不能只数显示字形。

<a id="e-evidence"></a>

## 关键证据与首次异常

适用阶段：执行。

及时保留关键 UI 结果的真实截图、对象和上下文，结合事实说明观察范围；偶发异常也保留首次证据与复现限制。

不适用与边界：不要求每步截图或发现问题配额；不安全的复现不强做，不能因未稳定复现抹掉观察，也不能补造截图。

具体场景（合成）：首次保存报错，后续成功且难以复现。保存首次真实画面、身份、对象、关键输入与错误回执，后续尝试独立记录，检查证据对应的目标和时点。

候选观察与判断：偶发观察仍保留，但证据是否足以判违反要结合明确要求。首次缺图如实记录缺口，补拍标注实际来源，不冒充首次现场；不为补图重放危险操作或要求每步截图。

子场景：截图失败、窗口最小化或零视口。先保留截图错误，核对此前业务动作是否已生效，再检查当次窗口/视口状态。最小化只是历史出现过的候选原因，不是所有截图失败的诊断。仅在授权内恢复本任务拥有的窗口，补图注明实际时点；恢复失败则披露证据限制。

<a id="e-cancel"></a>

## 取消返回与恢复

适用阶段：执行。

依据规则区分关闭界面、取消提交、保存草稿和撤销业务；核对原对象及必要状态是否符合目标。

不适用与边界：关闭弹窗不证明未产生副作用；撤销也可能是写操作，不默认总是可逆。

具体场景（合成）：填写记录后关闭弹窗，再进页面出现草稿。先确认关闭、取消、保存草稿和撤销各自的规则，记录实际执行的动作，不把这些动作当同义词。

候选观察与判断：检查草稿或业务对象是否存在及其内容、状态，分别对应明确规则。弹窗消失只能证明界面关闭；主动删掉草稿不能证明原取消操作没有写入。不适用例：无取消语义依据时保留待澄清，不默认所有关闭都应丢弃数据或总可撤销。

<a id="e-list"></a>

## 列表筛选与分页

适用阶段：执行。

先对齐查询条件、集合范围、排序、分页及对象标识，再判断遗漏、重复或操作范围，批量选择尤其注意当前页与全结果集区别。

不适用与边界：筛选隐藏不等于数据被删除；列表旧值不直接证明后端丢失，实时变化的数据不能机械比较总数。

具体场景（合成）：目标从第一页消失，怀疑数据丢失。保留关键词、筛选、排序、页码、对象标识和观察时点，按授权范围调整查询并寻找同一对象。

候选观察与判断：区分筛选隐藏、排序跨页、权限变化与确实不存在；当页不展示不是删除证据。实时总数变化不直接等于丢失数量，批量操作要核对所选集合。

子场景：动态页面误定位、同名按钮或旧引用失效。列表重排后原位置的删除按钮可能属于另一对象，应重新观察并用业务标识确认目标，不只刷新引用就默认正确。若已误操作，停止相关危险动作、保留事实并核对影响；不把定位错误记成产品缺陷，恢复仍需授权。

<a id="e-file"></a>

## 文件导入导出

适用阶段：执行。

核对授权文件、内容与记录范围、格式转换和部分成功；只在实际获得文件并核验后声称结果，保留错误项与成功项区别。

不适用与边界：下载回执不是内容正确；敏感文件不自动上传，文件名相同不代表内容相同，往返不必然逐字节一致。

具体场景（合成）：导入 5 行，提示 3 行成功、2 行失败。保留源行标识、成功/失败集合和错误明细，核对哪些对象实际形成、有无重复或部分字段写入。

候选观察与判断：重试前按实际状态排除已处理项，依据明确的重复/事务规则选择后续动作；不能将提示计数直接当作逐行结果。导出须取得文件，核对范围、字段及关键值，任务回执或同名文件都不够。不适用例：格式转换可能合法改变字节；不自动上传敏感文件，也不假设导入失败必然整批回滚。

<a id="e-time"></a>

## 时间与地域

适用阶段：执行。

对齐业务时区、显示与存储口径、日期边界和实际观察时刻，区分格式变化和数值变化。

不适用与边界：不要用本机时区替代明确业务时区；没有权限不修改系统时间，不假定所有月份或日期偏移相同。

具体场景（合成）：业务时区 UTC+8，零点附近记录在日期筛选中消失。记录业务时区、显示时间、观察时刻及筛选区间和端点定义，选用时间已知且获准读取的边界前后记录。

候选观察与判断：核对纳入/排除结果，区分显示格式与实际时间偏移；无存储观察权限时不猜底层值。区间规则未知先澄清。不适用例：涉及夏令时、月份长度或地域数字格式时不能套固定小时/天偏移；不为制造条件自行修改系统时间。
