# 执行观察与异常经验

执行方法可自主选择，实际授权、固定条件和验收标准不可替换。

<a id="e-permission"></a>

## 核验实际身份与范围

适用阶段：执行。

核对实际身份、租户、对象归属及授权目标。分别观察入口、操作和业务结果，结论只覆盖真正验证的层次。

不适用与边界：登录成功或 Space 名不是角色证据；看不到按钮不证明后端授权，不能换管理员绕过原目标。

<a id="e-unknown-submit"></a>

## 提交未知与重复操作

适用阶段：执行。

先保留首次现象，利用授权内的安全观察核对同一对象是否已产生副作用，再决定等待、继续观察或说明未知。实际可用接口数据可辅助，不假定已有监控工具。

不适用与边界：没有重复提交契约或结果证据时不要反复点击；数据已保存不能抹掉不符合要求的 UI 反馈。

<a id="e-async"></a>

## 异步与状态观察

适用阶段：执行。

区分请求受理、中间状态和业务完成，按已知时限与可观察信号选择等待和复查；记录观察时点及范围。

不适用与边界：没有时限依据不自设三秒失败；等待不无限继续，停止时说明未完成观察而不是猜通过。

<a id="e-input"></a>

## 输入方式与边界

适用阶段：执行。

核对实际输入、控件转换和提交后结果是否对应原样本。必要时区分键入、粘贴等操作语义并保留要求。

不适用与边界：不要把控件自动修正后的值当原边界样本已测试；不得暗改固定输入以得到成功。

<a id="e-evidence"></a>

## 关键证据与首次异常

适用阶段：执行。

及时保留关键 UI 结果的真实截图、对象和上下文，结合事实说明观察范围；偶发异常也保留首次证据与复现限制。

不适用与边界：不要求每步截图或发现问题配额；不安全的复现不强做，不能因未稳定复现抹掉观察，也不能补造截图。

<a id="e-cancel"></a>

## 取消返回与恢复

适用阶段：执行。

依据规则区分关闭界面、取消提交、保存草稿和撤销业务；核对原对象及必要状态是否符合目标。

不适用与边界：关闭弹窗不证明未产生副作用；撤销也可能是写操作，不默认总是可逆。

<a id="e-list"></a>

## 列表筛选与分页

适用阶段：执行。

先对齐查询条件、集合范围、排序、分页及对象标识，再判断遗漏、重复或操作范围，批量选择尤其注意当前页与全结果集区别。

不适用与边界：筛选隐藏不等于数据被删除；列表旧值不直接证明后端丢失，实时变化的数据不能机械比较总数。

<a id="e-file"></a>

## 文件导入导出

适用阶段：执行。

核对授权文件、内容与记录范围、格式转换和部分成功；只在实际获得文件并核验后声称结果，保留错误项与成功项区别。

不适用与边界：下载回执不是内容正确；敏感文件不自动上传，文件名相同不代表内容相同，往返不必然逐字节一致。

<a id="e-time"></a>

## 时间与地域

适用阶段：执行。

对齐业务时区、显示与存储口径、日期边界和实际观察时刻，区分格式变化和数值变化。

不适用与边界：不要用本机时区替代明确业务时区；没有权限不修改系统时间，不假定所有月份或日期偏移相同。


<a id="e-targeted-observation"></a>

## 按需获取可区分解释的观察

适用阶段：执行。当前 Ego 版本的具体能力须以官方文档和隔离能力验证为据；本节是选择方法的建议，不表示所有能力已通过验证，也不定义固定诊断顺序。

| 现象 | 可选观察 | 判断边界 |
| --- | --- | --- |
| 保存后界面不变 | 同一对象、实际输入、产品支持的提交方式、动作回执、重新进入后的读回；需要时查询相关请求/错误 | 根因未知不阻止已有充分证据的违反结论；Enter 补试不自动等于再次点击保存 |
| 拖动后日期不变 | 时间条身份、视口和命中信息、动作前后状态、拖动反馈、独立读回；需要时查看已采集请求 | mouse 调用成功不证明应用处理；日期未变不自动证明 Ego 缺陷 |
| AI 未体现上下文 | 已选对象/筛选、目标请求必要字段、可见回答或能力结果 | 模型自述不能证明上下文传输情况，权限应作为独立目标 |
| 下载监听超时 | 触发前准备适当监听、来源页和派生页关联、下载事件/错误、文件是否取得及内容核验 | 事件超时不等于未下载；文件取得不等于内容正确，不忽略已经提前监听的事实 |

不适用与边界：AI 只查询与目标和授权相关的页面、时间窗口、方法/路径或请求 ID，先摘要后按需展开，限定数量和字节；不把整站接口正文塞进上下文。记录实际采集范围和限制，未采集或已过窗口不能写成“没有请求”。不要保存 token、Cookie、认证头、签名 URL 或无关业务内容。

保留原始动作与结果来源，引用到 observations；必要时将诊断证据与业务证据分别说明。工具仅采集/查询/保存，不自动重试、改变业务路线或判断结果。具备能力名称不等于本机可用，隔离合成验证也不代表 UAT 业务验收。


下载可能归属于来源页、稳定子页或迅速关闭的派生页。父页已经提前监听仍可能未取得临时页下载事件；记录实际监听对象、窗口、服务器/浏览器事实和未取得的文件，不机械重复同一路径，也不以 fetch 取代必须经 UI 的下载验收。六秒等观测窗口是本次采集边界，除非需求规定，不能直接当作产品失败时限。

动作回执若为空或仅表示命令返回，不证明命中了正确 target。结合当前页面对象、输入、实际可见反馈或需要时的事件事实确认操作语义；允许根因未知，但不能用空回执填补必要动作证据。窗口恢复仅限本次拥有且当前授权明确的对象，使用当前官方 API 与实际 tabs 返回的标识，保留首次失败及恢复限制。
