# 测试数据与副作用经验

执行方法可自主选择，实际授权、固定条件和验收标准不可替换。

<a id="e-delete-data"></a>

## 删除与批量对象

适用阶段：执行。

普通删除优先使用本轮创建、身份明确且获准删除的数据，保留稳定标识和关联事实。批量操作核对实际集合、选择范围及每类结果，不只看成功提示。

不适用与边界：历史、他人归属或特殊状态用例不能用新建自身对象替代。软删、回收站、永久删除以规则为准；创建和清理也不自动获得授权。

<a id="e-edit-save"></a>

## 编辑与保存副作用

适用阶段：执行。

确认原值、目标对象和需要改变的字段，观察保存后的实际属性及必要持久化。区分本次更改与他人并发更改。

不适用与边界：恢复原值也可能覆盖他人新修改，不把“测试清理”当无条件回滚许可；不得为通过而改固定输入。
