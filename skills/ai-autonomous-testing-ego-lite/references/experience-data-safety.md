# 测试数据与副作用经验

执行方法可自主选择，实际授权、固定条件和验收标准不可替换。

<a id="e-delete-data"></a>

## 删除与批量对象

适用阶段：执行。

普通删除优先使用本轮创建、身份明确且获准删除的数据，保留稳定标识和关联事实。批量操作核对实际集合、选择范围及每类结果，不只看成功提示。

不适用与边界：历史、他人归属或特殊状态用例不能用新建自身对象替代。软删、回收站、永久删除以规则为准；创建和清理也不自动获得授权。

具体场景（合成）：选中 A、B 删除后提示成功，B 仍可见。保留稳定标识、归属、关联状态及当前页/全部筛选范围，避免把同名记录或页面位置当身份。

候选观察与判断：分别重新读取 A、B 及规则要求的关联影响，区分删除成功、拒绝、软删后仍展示和观察不足。失败原因只记录实际回执，不臆测关联限制。若目标要求历史关联对象，不换成新建空对象；普通自建自删仍须创建和删除授权。

子场景：清理或回滚后的独立确认。测试结束后恢复角色或清理对象，不能只凭成功提示声称环境恢复；在授权内重新读取最终状态，分别记录测试结果与清理结果。清理失败不抹掉发现，恢复也不允许覆盖他人新修改。

<a id="e-edit-save"></a>

## 编辑与保存副作用

适用阶段：执行。

确认原值、目标对象和需要改变的字段，观察保存后的实际属性及必要持久化。区分本次更改与他人并发更改。

不适用与边界：恢复原值也可能覆盖他人新修改，不把“测试清理”当无条件回滚许可；不得为通过而改固定输入。

具体场景（合成）：只修改名称，却发现标签也变化。记录同一对象编辑前后值、实际修改字段和观察时点，查明有无他人同时修改的事实，而不是直接把所有变化归因于本次保存。

候选观察与判断：重新读取同一对象，分别检查目标字段及需求明确要求不变的字段。发现差异可报告事实；缺并发或转换规则时不凭差异猜根因。不适用例：不能将整份旧快照写回作为无条件清理。

子场景：多个页面或测试共享后端数据。两个页面读取旧值后先后保存，记录各自读取/保存时点及字段变化，依据已知冲突规则判断；Space 不等于后端隔离。无需为了套用例子主动增加并发；自身数据干扰与产品违反分别记录。
