# 证据与报告

## 记录足以复核的事实

在私有工作区保留任务约定、需求来源及版本、计划检查列表、执行时间与环境版本。每项检查记录实际前提、路径、动作、观察、判断依据、状态、归因与剩余问题；报告只引用实际存在的证据。不要粘贴凭据或签名下载 URL。

证据类型与采集时机由 AI 根据风险、判断需要和授权自主决定，不要为每个点击强制截图。对关键动作留行动前状态、动作后结果及必要的持久化观察；关键页面结果优先调用本机已安装 Ego 官方能力取得截图，再登记需要留存的本地文件。截图和语义快照互补：截图不证明完整流程，DOM 可读不证明视觉或权限正确。按钮从 disabled 变成 enabled、点击成功提示、API 调用成功或工具回执，只能证明相应界面/调用事实；不足以证明业务提交成功。要检查目标结果，并在要求持久化时通过刷新、重新读取或其他授权的独立观察确认。缺失证据、采集错误、脱敏造成的不可判定区域都应说明。文件哈希可以发现字节变化，不能证明内容真实或结论正确。

清理或重置测试数据前，先确认需要的首次失败、恢复过程和最终确认事实已保存，相关文件已登记，并且报告已生成及检查可打开。保留原始观察，不因恢复成功清除失败记录。没有截图不自动意味着失败；应标出证据缺口及其对判断的影响。

若使用本地工具箱，先确认工具包仓库根目录，再读 [本地工具箱调用指南](local-toolbox.md) 与 [资产格式约定](../../../docs/asset-formats.md)。该指南定义当前 schemaVersion 3 命令及请求字段，不要另造格式或直接编辑结果/catalog 文件。记录项至少要与冻结用例关联；证据 ID 必须由本地登记工具返回。若工具不可用，继续用私有 Markdown 记录，不伪造工具输出、hash、采集时间或报告。未执行 Ego 时保持未执行，绝不填模拟通过冒充实测。

## 保留业务语义

用例的 `basis`、关键条件、整体 `expected`、必经路径、步骤和顺序策略来自冻结基线。步骤表达业务意图与必要输入；具体 UI 定位由 AI 自主使用 Ego 探索。每步 `expected` 可省略；仅对有依据的独立 checkpoint 填写。省略不等于该步骤未执行，也不产生隐含通过结论。

`clarificationQuestions` 是冻结验收条件的一部分。非空时，该用例的**最终结果和每一条历史尝试**均不得为 `pass` 或 `fail`。不得通过清空问题、删除历史或补造 step expected 绕过限制。澄清后创建并冻结修订用例，保留旧基线与结果。

可选工具区分当前最终状态与历史尝试：`mode: final` 更新当前结果；`mode: attempt` 追加 observation，不改变最终状态。历史失败保留一次但不重复计入当前进度。被替换的最终 observation 会保留为历史快照。`not_run` 表示尚无最终结论，可能已有尝试；只有 `not_run` 且没有 attempt 才算从未尝试。报告概览会分别显示从未尝试与已尝试但无最终结论。

## 报告应回答什么

先说明目标覆盖和状态去向，分别列出明确需求结论、解释与探索观察。包含未覆盖项、阻塞、首次失败与补测、证据位置、来源依据、归因及下一步。不要仅用 pass/(pass+fail) 报告一个会掩盖阻塞或未知项的“通过率”。报告需明确区分**已观察**（AI 实际看到或获准读取）、**已保存**（证据文件已复制/登记，能在本地校验）、**已交付**（报告/附件已经放在约定且获准的位置）；其中一项不能冒充另一项。

运行 `report` 会生成 `report.json`、`report.md` 与独立可离线打开的 `report.html`。HTML 对每个用例展示冻结目标、需求依据、实际观察、判断理由、尝试历史和未验证项目；只内嵌 hash/字节数校验通过且可安全识别为 PNG、JPEG 或 WebP 的实际登记截图。缺少可预览截图时明确说明，不使用占位图，也不自动判产品失败。结构无效、哈希不匹配或悬空证据引用时，正常报告应被拒绝，不能悄悄生成似乎可信的通过报告。HTML 将业务状态与文件完整性分开；hash 匹配不是真实性或正确性认证。报告只支持用例级 verdict，没有独立步骤 verdict 时需明确提醒，不推断计划步骤已执行或全部满足。

每个重要发现应让读者看到：

1. 需求依据与分类、影响范围。
2. 已观察到的前提和最少复现路径。
3. 冻结预期、实际观察、关键证据及其采集/登记时间。
4. 当前归因、替代解释和需人工确认的事项。
5. 初次失败与补测的差异，及最小下一步检查建议。

生成报告只说明本地记录结构与哈希是否匹配，不是独立业务验证。不得把未授权建议描述为已执行，也不得声称 Windows、Ego 或真实项目兼容，除非确有对应环境的验证记录。

## 隐私与发布

仓库分发物只放原创 Skill、工具与合成 `.example` 示例。真实需求、站点、账户、截图、快照、日志和报告置于仓库外。私有 Git、哈希、ignore 规则与自动检查都不能保证无泄露。登记证据不会自动脱敏；优先不采集敏感字段，发布前人工检查源文件、当前树、历史和附件。
