## Report language and model provenance

Follow the user's communication language unless they specify an output language. Pass --presentation ABS_JSON to cases render or report; language is a BCP 47 tag and messages contains every source key exported by report/ui-catalog.mjs. English and French examples are included. The AI supplies another language using the same keys; templates never translate interpolated facts or silently fall back.

Optional aiContext.uses records model, reasoningEffort, sourceKind, SourceRef and scope in case-save requests, actual record payloads and report reading context.
