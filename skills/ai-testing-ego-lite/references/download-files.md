# 下载与只读文件检查

AI 显式组合以下工具能力，不以固定流程替代实际观察与业务判断。

## 轻量辅助函数

ego-helpers/download 普通模块，由当前 AI 的 Ego nodejs 脚本导入。它接收已选定 Page、本轮/用例/目标引用及绝对保管目录，不创建 Space、不找按钮、不选择业务路径。

当前辅助函数用法如下；先记录相同 captureId/caseId/pointIds/actionId 的 execution download active note：

```js
const capture = await armNativeDownload({
  page, runDir, runId, caseId, pointIds, actionId, captureId, captureRoot,
  startTimeoutMs: 30000,
  completionWaitMs: 60000
});
let actionReceipt = null, actionError = null;
try {
  actionReceipt = await page.click(chosenDownloadControl);
} catch (error) {
  actionError = describeError(error);
}
const facts = await capture.collect({ actionReceipt, actionError });
```

先请求官方监听并立即接住拒绝，再由 AI 明确发出所选动作，最后在同一脚本内完成 saveAs 或记录未知。只记录实际已请求监听的时间，不伪造底层监听器已就绪的证明。

函数不自动换定位、换页、fetch、再次点击或重发。动作错误也不能推定未发出，已有回执及 actionId 保留供 AI 对账。

## 事实放在本轮，不放进新库

capture JSON 作为普通工具事实，包含本轮 runId、caseId、支持的 pointIds、actionId/captureId、实际页面来源、观察时间、动作返回、建议文件名、实际文件字节/指纹、失败原文及局限。它不拥有独立项目生命周期。

启动观察为 observed/not_observed/unknown，完成观察为 completed/failed/unknown。未观察到事件不等于下载未启动；completed 也不等于业务数据正确。停止等待不等于传输停止。

报告仅展示必要 URL 范围；关联使用内存中完整 URL 的指纹，不把签名查询参数、Cookie 等写入通用资料或报告。targetId 只使用当轮实际取得值，不跨轮持久充当页面身份。

captureRoot 固定为 note 所属串行运行的 run/captures，或明确 assignment 的 workers/<assignment>/captures；更换目录不能绕过同一 capture 的独占。每个 capture 使用独占目录和全新文件，原始文件名只作描述，不能控制目录路径。拒绝覆盖、路径穿越、符号链接及文件身份变化。先保存独占 staging，在 saveAs 完成且文件核对后成为可登记原件。

原件、capture 事实、解析结果分别经现有 evidence-add/record 或工作包导入；worker 只写自己的目录，协调者审核后写公共账本。AI 的判断说明不能标为原始工具回执。

## 超时、并发与用户介入

启动与完成等待分开配置；默认 30/60 秒是工具等待预算，不是业务 SLA。真实异步导出需要怎样观察、等多久，由 AI 依据原要求和页面事实选择，不由固定下载流程判断。

完成等待超时后，返回 unknown 及 lateEffectsPossible=true。后台下载或 saveAs 可能继续；晚到回调只写独占 staging，不提交业务账本。后续必须显式对账再登记，不因文件出现自动判通过或删除可能在变化的文件。

当前 cancel API 实测不可依赖，临时文件在轮次后也曾继续存在；不得假定退出脚本已取消传输或清理完毕。未知后先核对原动作与文件，换 captureId 不构成重发许可。

下载观察涉及共享设置。普通顺序执行继续使用串行等待；本任务启用并行时，协调者通过已有 execution 事务记录一个在途下载标记，按用例安排下载观察串行化。使用现有 note/对账数据，不另建调度服务。

未知标记不按时间自动清除或重派；AI 选择对账、等待、交接或继续不依赖下载的目标。此机制只协调当前任务，不隔离其他对话或用户下载。

用户接管、Space 失控或出现浏览器原生确认时停止主动动作，必要时 handOff 同一 Space，说明具体需要处理的提示。收到用户回复后恢复同一任务，不新建 Space 绕过阻塞。

## 显式下载管理补证

保留两个普通能力：读取本任务范围的下载候选，以及保管 AI 明确选定候选的实际文件。不在原生等待失败后自动串联成恢复路线。

在同一 Space 的自有页读取下载管理页；浏览器内先按授权来源过滤，返回记录 ID、原始状态、来源指纹与文件引用，不返回无关下载历史。

有条件时保留动作前 ID 集合，之后用新增 ID 与来源缩小候选。同一 URL 多次下载、同名或同大小都不能单独证明归属。多个候选完整返回，工具不默认选最后一条。

临时页消失时可以取得已发生下载的文件，不需要重新请求 URL。没有动作前快照、关联不唯一或文件不可读时说明限制，由 AI 补证或保留无法判断。

适配只针对已验证版本，未识别状态原样保留并按未知处理。需按当前实际状态区分进行中、完成、中断、已删除或不可读，同 URL 多条时不能擅自选取；版本或页面结构不符明确报不支持，不静默改成目录扫描或 fetch。

## 文件检查

files inspect 仅接收实际文件、读取方式和边界，输出有类型及范围的数据事实，不接收自动判通过条件。AI 再对照需求判断。

| 方式 | 支持 | 限制 |
| --- | --- | --- |
| bytes | 任意普通文件的大小、指纹、与指定原件的字节比较 | 相等不代表其他业务标准成立 |
| text | UTF-8 TXT/Markdown 及明确窗口 | 其他编码必须声明或说明不支持，不静默替换乱码 |
| json | 结构、路径/窗口、类型及原文 | 不补默认值；数值精度不足时不能以舍入值证明精确数据 |
| csv | 正规引号、BOM、跨行、行列读取 | 保留字符串、前导零、空记录及重复表头，不自动变字典覆盖数据 |
| xlsx | 工作表及常用值读取 | 不执行宏、不重算公式，不保证完整样式及公式/空值消歧 |
| 其他格式 | 原件与 bytes 事实 | 语义检查缺口仍保留目标，AI 可选其他已获准能力 |

CSV 不用 split(',')，不默认 trim。XLSX 使用 trim:false，数值保留带类型的原始十进制文本，日期独立表示。缺缓存/错误公式可能与空值混淆、末尾空区域可能被读取器省略；需要核对这些语义的目标必须补充观察，不能仅凭值读取结果报通过。

JSON 保留原始文本和类型；能取得可靠数值原文时一并保存，否则明确精度限制，不能靠浮点近似证明长整数 ID 或精确金额。读取完整性针对本次方式和窗口，不等于整个文件所有业务含义均已验证。

## 读取与交付边界

读取依赖已预打包，无需运行时 npm install。files inspect 从独立 Node CLI 调用，默认单文件 32 MiB、解析正文 4 MiB、表格 100000 单元格和解析 60 秒；可在授权内显式调整，它们不是业务上限。超限、部分、不支持和失败分别返回；窗口结果仅支持已读范围。停止解析不取消浏览器下载，不自动重试。

观察引用本轮实际动作、capture 事实、原件及解析结果。原件交付选择完整 bundle，二进制作为附件；文件、反馈、公式及主动 HTML 一律作为数据，不执行其内容。第三方完整许可见 ToolRoot/vendor/THIRD-PARTY-LICENSES.txt。


## 历史受控验证与适配边界

以下原文从执行经验迁入，保留 0.1.8 当时的验证范围和局限，不代表本次重新验证 Ego 版本或真实业务。

补充验证（0.1.8）：本机 Ego 0.6.2.5 的受控自测中，普通页、Blob、异步及稳定子页可提前监听并在同轮 saveAs；临时新页的父页监听漏收，但精确 URL 范围内的新下载 ID 已完成。可以显式选用下载管理页补证，保留动作前后快照与原生未知事实，不能自动改成 fetch、最新同名文件或重复点击。该内部页适配有版本边界，不外推到所有 Ego 版本。

慢速下载停止等待后仍可能完成；未知在途标记先保留，显式对账再登记文件。管理页状态、实际原件与解析输出分源，零字节是可核验事实，不自动等于正常内容。CSV 保留字符串、重复表头及前导零；XLSX 只读值和缓存，公式/空值语义不足时保留缺口。下载完成、取得原件和内容符合业务预期分别判断。

下载可能归属于来源页、稳定子页或迅速关闭的派生页。父页已经提前监听仍可能未取得临时页下载事件；记录实际监听对象、窗口、服务器/浏览器事实和未取得的文件，不机械重复同一路径，也不以 fetch 取代必须经 UI 的下载验收。六秒等观测窗口是本次采集边界，除非需求规定，不能直接当作产品失败时限。
