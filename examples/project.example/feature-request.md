# 虚构新功能需求：书签归档

这是供 Skill 自行生成用例的新功能需求示例，不是可执行测试服务、能力验收数据集或已运行报告。它延续共享书签目录的虚构场景；目标地址仅为 https://catalog.example，实际使用者应在仓库外提供真实的私有项目资料。

## F-01 归档行为

编辑者可以从书签详情将一条“有效”书签归档。完成后显示“已归档”，刷新详情仍显示“已归档”；默认有效书签列表不再显示该条目。

## F-02 角色边界

读者可以查看已有书签，但详情页不能提供可用的归档入口。

## F-03 已归档状态

对于已归档的书签，详情显示“已归档”，不再提供可用的归档入口。本需求没有规定恢复归档功能，不应自行添加恢复操作。

## F-04 批量归档（验收细节待澄清）

支持批量归档选中的书签。部分条目无权限时是全部拒绝还是部分成功，以及如何呈现各项结果，本需求暂未规定。对应 G-04 保留已知目标与 clarificationQuestions；不能自行补出对话框、提示或部分成功规则。
