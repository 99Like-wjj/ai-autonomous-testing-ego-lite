## 1. 目标与已确认选择

本版降低无新增判断价值的模型往返、重复上下文读取和集中收尾成本，并准备一次性名称替换。AI继续自主选择业务路径、观察方式、停止或补测及业务四态；代码只处理确定性事务、投影、统计和一致性检查。

本次设计承接执行效率优化方案，但区分已证实的编排现象、工具能力缺口与外部测试条件。不能把所有成本变化归为知识检索，也不能把与某类请求关联的token认定为修改后必然可节省的token。

用户后续约定已纳入：

- README中文名称保留“AI 自主自动化测试”，可保留“· Ego Lite”技术标识。
- 仓库与 Skill 短标识已由用户确定为 `ai-testing-ego-lite`；下文`<new-name>`在本次实现中指该标识。
- 检索定位为“AI 自动化测试 / AI testing”；名称、仓库简介、Topics、中英文README协同表达，不能承诺搜索排名。
- 下次安装完整新名称Skill，确认可加载后删除旧名称Skill；不提供旧名别名、双入口兼容或历史格式转换。
- 删除旧Skill安装不包含删除历史运行、报告、证据、用户知识或不属于安装包的文件。

详见[效率接口与行为](v0.2.1-efficiency-design.md)及[更名与检索设计](v0.2.1-rename-design.md)。

## 3. 实施边界

本版计划包含三组可独立评审的变更：

1. **执行指导及观测样本**：同一次编排内顺序准备/执行的例子、摘要/原文使用方法、及时入账与命令文档修正。
2. **小型工具增量**：目标读取投影、当前提交质量反馈、可选usage归并。根据第一组实测决定增量先后，不以“把框架做全”为目标。
3. **名称及分发一致性**：最终名称确定后同步身份、路径、调用名、当前文档与安装说明；仓库实际更名、安装替换及发布按对应阶段执行。

不增加固定业务状态机、自动业务重试、自动下一步推荐、每N步强制检查、自动压缩宿主会话、默认并发、旧名分发别名、旧资产兜底解析或通用批量写入引擎。必要业务语义和真实证据要求不降低。

## 4. 契约与数据影响

| 项目 | 决定 |
|---|---|
| cases / results / evidence / manifest / report等存储结构 | 继续v9；新增能力不重写这些历史文件 |
| 知识格式与回归格式 | 继续knowledgeFormatVersion 3、regressionVersion 2 |
| progress/context的新读取输出 | 独立`contextReadVersion: 1`；不伪装成业务资产schemaVersion升级 |
| CLI record反馈输出 | 独立`recordResponseVersion: 1`；保留嵌套原ResultReceipt；CLI消费者需同步 |
| usage输入/摘要 | 独立`usageVersion: 1` / `usageSummaryVersion: 1`；默认不进入业务报告与运行账本 |
| 包身份 | 最终新名；开发实现用0.2.1-rc.1，正式发布才用0.2.1 |
| 旧历史 | 不自动迁移。自包含报告保持原样；历史绝对路径可能失效，不能笼统承诺全部旧run可在新路径复核 |

如果实现中发现必须改变业务存储语义，应返回此设计解释影响，不能偷偷扩大格式范围。源码本来就严格核对v9与身份，名称变化不授权改用户资产。[VERIFY: src/execution/read-context.mts:9-15] [VERIFY: src/scripts/toolchain.mts:43-59]

## 6. 验收与实施顺序

| 阶段 | 工作 | 出口证据 |
|---|---|---|
| A | 指导、文档修正、固定合成任务基线 | 可确定的准备和执行不再被无故拆开；失败及中间判断分支仍保留 |
| B | 目标投影、入账反馈 | 相同revision下与完整读取一致；省略可定位；提交/提示/幂等语义清晰 |
| C | usage摘要 | 重复不重计、子项不重加、缺失不写0；无模型或外部业务调用 |
| D | 新身份和路径统一 | clean build、tool-info、运行文件集合及包内引用一致 |
| E | 同范围效果对比 | 相同目标、初态、模型声明、授权与证据标准；报告调用数、token及质量限制 |
| F | 仓库更名、完整包替换安装、正式发布 | 只在对应发布/安装阶段执行，包含实际新会话加载验证 |

阶段A到E的工程验证按改动范围先跑对应检查；提交前完成typecheck、npm test、check:public及diff检查。合成任务只是工具和方法验证，不能冒充真实业务验收。真实环境测试当前仍暂缓。

效果不预先承诺固定百分比。若请求数减少但证据不足或目标遗漏，不能算优化成功；若仅输出字节减少而宿主仍携带大历史，不能据此报告token已同比下降。
