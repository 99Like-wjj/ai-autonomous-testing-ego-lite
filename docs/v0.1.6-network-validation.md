# v0.1.6 接口观测开发与自测

已以最终设计 v3 完成开发和限定范围自测。候选为 **0.1.6-rc.1 / native-network-observation-1**，网络数据独立使用 **networkVersion 1**，既有 v5 用例、证据、目标评估及报告契约保持。

本次是 Windows + Ego 0.6.1.13、本地合成数据、业务串行场景的工程验证。真实 UAT/生产、其他宿主及 Ego 构建未测试；用户级安装、推送和正式发布未执行。

## 实现范围

- 统一 CLI 的 network start/status/query/stop；一个 Run 同时一份活跃采集，恢复另建段。
- 独立 native-only 上下文、自有 session 与回调所有权检查。真实 UI 保持官方 TaskSpace/Page 操作。
- Fetch/XHR 请求与响应、200 业务错误、HTTP 错误、202/页面后续请求、取消/超时、重定向和重复请求关联。
- EventSource、POST Fetch/XHR SSE 的非空前缀、UTF-8 增量、CRLF、多行 data 及边界；WebSocket 双向文本/二进制、浏览器重组消息和关闭/错误事实。
- 明确登记的顶层目标、页面来源及接口路径；普通导航、同一目标 session 更替和明确的新段登记。独立 iframe/worker/service-worker 不自动接入。
- 处理后正文、行顺序哈希、检查点、缺口、范围/内容/容量限制、分页和不可变片段导出。协议时钟、接收、正文读取和提交时间分别保留。
- Skill 按需场景与真实入口指引。采集和查询不重发业务请求、不自动轮询业务、不写业务结论；AI 自主选择查询、证据及下一步。

普通 HTTP 在完整 JSON 值或未压缩 Content-Length 对齐的安全单元可取得时，允许查询正文。没有真实结束事件时保持 in_progress / response_end_not_observed，不因内容已取得就宣称响应完成。

默认单正文 512 KiB、Run 采集数据预算 64 MiB（含先前采集段）、事件队列 4096 条/8 MiB、关联表 4096 项、查询输出 256 KiB。流单元在处理后落盘；超限和获取失败保留缺口，已有记录不滚动覆盖。

## 量测、清理和失败保留

- 开发中相同接入路径的十次 UI 点击样本：采集中中位数 116 ms，停止后 117 ms。这是本机小样本，不能当作所有版本或负载的性能认证。最终包另完成真实 UI/接口功能复测。
- 该量测段队列峰值 28 条、25856 字节，待处理正文峰值 360 字节。共享嵌入运行时 heap 峰值约 9.7 MiB，不归因为采集器独占内存。
- 受控交接后服务端继续发送 3 个 SSE 块，已停止采集文件保持不变；独立诊断目标的附着状态完成 false/true/false/true/false 读回。正常停止另有真实 disable/detach 回执。
- 全部 9 段上下文和启动句柄均已结束；其中含保留的失败/部分采集段，不将每一段都计为完整成功。自建测试 Space 已 finish 并独立读回不存在，原用户 Space 保留；两组合成服务的四个端口关闭，服务进程退出 0。
- 观察到页面不消费 Fetch 响应时没有及时 loadingFinished，已补齐安全在途正文；始终区分取得内容与确认结束。
- 观察到一次启动 local_io_EPERM。运行时检查点加入有界纯文件事务重试，故障注入证明不重复事件，最终包真实启停通过；会话元数据超过预算在创建采集历史前拒绝。
- 初次截图超时、Ego SDK 状态文件锁、含空格打包参数转发、测试驱动闭包仍指旧工具根、复用旧日志造成提前关流等首轮问题均保留原始材料。用户重启 Ego 后标准恢复/UI 复测通过；最终包以显式工具根和精确指纹重新取证。

## 已知限制

通用过滤不识别一切敏感值，不透明 WS 二进制应按项目授权决定 include/omit；严格场景选择允许字段或禁采正文。查询为空、HTTP 200/202、失败事件或缺口均不等于业务结果。普通 HTTP 二进制/上传下载默认仅元数据。

用户接管检查与落盘存在竞态；没有显式 detach 回执时只报告宿主上下文收尾。真实全部崩溃、超高负载、多 worker 并行、其他宿主/浏览器构建及 UAT/生产均未完成验收。当前包是候选开发交付，未自动安装或正式发布。
