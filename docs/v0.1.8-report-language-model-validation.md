# 报告语言与两阶段模型来源：开发验证

日期：2026-11-02。工具：0.1.8-rc.2 / report-language-model-1。状态：开发及本地验证完成，开发修订尚未正式发布。

## 变更范围

- 报告语言按用户交流语言选择，显式指定优先；正文由AI按所选语言撰写，固定界面文案由同源映射提供。原始事实及证据插值不翻译。
- 用例报告、测试报告各显示一处模型和思考等级；测试执行阶段包含执行判断与报告分析。来源、多个配置及未知项分别保管。
- 新增可选v9 aiContext和展示参数，保留来源文件指纹、幂等事务身份、工作包归属和精确用例绑定；模型来源不改变业务目标定义指纹。
- 场景标题下方展示完整可换行编号；首次执行与回归使用同一份基于明确比较基准的文案投影。

设计见[优化方案](v0.1.8-report-language-model-design.md)，专项测试见[语言与模型来源测试](../tests/report-language-model.test.mts)。

## 验证方法与当前结果

1. 工程全量测试最终记录：227项，226通过、0失败、1跳过。跳过项是当前Windows没有符号链接创建权限的公开内容符号链接检查；未修改跳过条件，也未将其计作通过。
2. 专项覆盖模型来源解析、未知和多配置、来源文件失配、幂等重取、工作包证据映射、原生成者保留、事后补充不覆盖已知来源、目标指纹不变、报告精确读回、语言映射完整性、占位符、HTML转义及并发语言隔离。
3. 本机HTTP审阅页验证所选法语随页面交付和原生反馈保存保留；反馈保存不改用例或登记正式确认。
4. 使用真实Ego Lite v2.2.0打开中文、英文和法语的用例HTML及测试报告，检查两阶段模型头部、页面文案、步骤/结果及原始证据。数据和模型标识均明确为合成工程资料。
5. 在390、768、1024和1440像素宽度核对布局；页面没有横向溢出，长场景编号保持完整可见。检查过法语评审工作台、返回总览后的草稿、无匹配筛选、重置及证据库的当前/历史引用筛选。
6. 展开证据后确认包含其他语言的原始内容仍保持原文；折叠状态下不能以innerText没有内容推断来源丢失。

原始浏览器截图、观察JSON、生成的合成报告及逐轮脚本保存在仓库外的本机验证目录。页面截图证明本轮真实离线页面展示，不是被测业务系统的验收截图。

## 自测中修复和澄清的事项

- 新指南最初放入错误暂存分组，已改用referenceNames；独立包检查发现README引用的新设计文档未随运行时暂存，已补齐清单。
- 本地化后发现动态aria-label中的译文需要转义，已修复；目标语言必须提供完整文案，格式参数也必须保留，不能静默回退。
- “模型已知、思考等级未知”只显示等级未记录；不会把它误称为来源未记录。真正缺失贡献来源的情况保留单独提示。
- 浏览器验证脚本曾因返回总览后仍保留展开态而多点一次按钮，导致目标隐藏。读取实际状态后修正脚本并完成草稿验证；这是验证脚本定位问题，不是产品失败。各轮脚本与原回执保留。

## 适用范围

工程和合成页面验证不证明AI一定正确选择用户语言、提供准确翻译、保管真实宿主模型信息或作出正确业务判断。本地工具不识别宿主、不调用模型、不自动执行测试路线，也不根据模型名或思考等级给业务结论。

没有重新运行真实UAT，原用例、运行、业务判断和历史报告未改写。尚未生成或安装候选包，也未创建Tag或Release。

最新构建再次生成并打开三种语言的两类报告，模型字段与语言一致；另用含ASCII双引号的展开/收起文案检查真实DOM属性，确认完整保留且正确转义。最终公开内容检查、类型检查、Skill校验和差异空白检查均在提交前执行。
