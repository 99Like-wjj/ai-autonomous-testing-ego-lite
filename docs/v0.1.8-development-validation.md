## 实现结果

- 长期资料只有用例整份版本、相邻实际审阅与独立运行。稳定 pointId 在整份保存事务中分配；回执丢失可恢复，冲突不覆盖，退役编号不复用。普通重测不生成新用例版本。
- 同源 HTML/Markdown 用例文档提供编号检索、范围选择与意见导出。实际确认有来源和内容指纹，未改目标复用确认，较新修改要求不能被旧确认绕过；离线 approved 字段不成为后台审批。
- points/status/full 范围、明确步骤依赖、类型化参数与当前条件独立冻结。baseline 保留完整原件，binding 只保留执行引用；串行与工作包拒绝为未选点提交正式评估。
- 下载主体复用官方监听与 saveAs。本项目提供独占保管、既有 execution 在途标记、显式管理页补证与只读文件检查。超时保持未知，晚到结果显式对账，无自动 fetch、换路径或重发。
- 原问题直接引用旧 finding 或精确评估。报告保存旧定义、必要计划、当时条件、原判断及原证据，当前四态独立统计。历史目录移动可显式映射；完整附件包可在原目录不在原位置时继续校验。
- auto 需要下载原件或历史附件时交付 bundle。读取库预打包并附许可，运行时无需安装依赖；没有增加通用资产库、问题库、租约服务、固定评分或业务决策引擎。

主契约为 v9，regressionVersion 为 2，networkVersion 仍为 1。旧格式不兜底读取，旧资料不迁移、搬运或删除。已安装 Skill 未被本次开发替换；未推送、合并、创建 Tag/Release 或交付候选安装包。

## 实际 Ego 下载与内容检查

环境：Windows、本机 Ego 0.6.2.5、官方指南 2.2.0、Ego 脚本 Node 24.22.1。仅操作自建 loopback 合成页面，没有进入真实业务站点或检查用户配置档案。

| 场景 | 实际观察 |
| --- | --- |
| 普通页、Blob、异步、稳定子页 | 提前监听，同轮 saveAs，取得独立原件并实际读取 |
| 临时新页附件 | 父页监听漏收，原事实保留为未知；明确选择动作前不存在的新 ID 37，完成状态后保管 49 字节原件，无重复点击 |
| 同 URL、同文件名、同大小 | 两次均为 22 字节，但实际编号为 00001 / 00002、指纹不同；分别保管 |
| 零字节文件 | 确认取得真实 0 字节文件，不混同文件缺失 |
| 慢速下载 | 40ms 完成等待返回 unknown，管理页实测 state=0；实际 SDK 晚到完成后显式保管 4096 字节，未知记录不覆盖 |
| 中断负例 | 原生报 canceled 且未取得完成原件；精确新 ID 40 的管理页状态为 5（interrupted），没有把超时推断成失败或自动重试 |
| 已知内容坏例 | 实际 CSV 为字符串 123，固定标准为 00123；下载完成与数据违反分别记录 |

首次受控运行有 11 场景、22 目标：19 已验证、2 发现违反、1 未测试。两项违反对应预设的内容丢零与中断；未测试是中断后没有完整原件可供数据检查。这是已知参考范围的逐目标 AI 复核，不是通用成功率、召回率或人工业务签字。
