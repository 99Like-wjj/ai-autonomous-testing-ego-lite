# v0.1.6-rc.1 目标评估改造：变更与验证

> 历史版本记录（v0.1.6）：以下“当前/尚未/待验证”等表述均以本文日期和阶段为准，不是 0.1.7 的最新状态。原始测试结果与限制保留；当前能力与契约见[格式说明](asset-formats.md)，分阶段验证见[云端审阅](v0.1.7-cloud-review.md)。

日期：2026-10-28。版本：`0.1.6-rc.1 / goal-assessment-1`，属于开发候选，未创建正式 Tag/Release。

## 变更

- P0：统一 v5 数据契约。case 组织业务流程，goal 是独立判断单位；必要步骤、前提和路径通过 requiredRefs 保留。串行 record 与复核后的并行 import 共用 observations、assessments 和追加式 results.entries。目标状态由 AI 明确提交，缺评估是记录缺口；父场景展示分布，不另存整体状态。
- P0：final 只更新提及目标，attempt 只保留历史；首个异常与原始封包不被覆盖。必要引用和证据归属、版本冲突、幂等重放、证据留存字节继续校验。违反可与未知根因并存。
- P0：HTML、JSON、Markdown 使用同一结果投影。保留截图、安全预览、历史、后续关联和来源说明；旧格式不读取、不转换，已有文件不被迁移或覆盖。
- P1：生成与审查目标时核对来源、前提、动作和观察；将表单反馈与未保存等不同目标分别表达。补充名称不能推导刻度单位、支持示例不能推导排他白名单的实例，以及结果与原因分离的正反例。
- P2：`observation/protocol.mjs` 提供原生已采集事件的有界摘要与查询，`protocol-query` 只读查询摘要。默认不解析正文，去除 headers、Cookie、URL 查询参数和原始 console 内容；显式字段白名单、容量、遗漏、原始时钟和未知完整性均记录。它不控制浏览器、不重试动作、不生成业务结论。

## 工程验证

Windows / Node.js v24.19.0：`npm test` 共 **88 项，87 PASS、0 FAIL、1 SKIP**。跳过项为文件符号链接创建权限不足；目录 junction 路径保护另有实测通过。构建含 schema 声明一致性、Node 与浏览器严格 TypeScript 编译及 runtime 清单核验。

覆盖目标投影、部分 final、历史 attempt、未知根因、必要语义、原始事实不可换内容、跨 case 引用、文件哈希、串并行一致性、并发容量/Space 保护、迟到结果、导入中断恢复、独立包、三格式报告、安全渲染，以及 11 项协议摘要边界测试。

首轮失败包括指南索引换行与安装包链接；新增协议查询测试发现 `//` 起始路径可被误当同源路径，已修正并保留失败日志。最终结果没有把这些失败抹作首轮通过。

Skill frontmatter 校验通过。默认 Windows Python 编码曾读取中文失败，改用 `python -X utf8` 后验证通过，未修改校验器。

## 独立使用与语义复核

独立上下文仅使用构建后的 Skill，从合成需求生成 15 个场景、27 个目标、51 个步骤，官方 validate-cases 通过，没有执行业务。首版语义复核发现两处不当扩展：视图名称被解释为内部刻度单位，以及“支持 TXT/MD”被解释为排他白名单。首版原样保留，另存修订版，全部原目标仍保留，结构再次校验通过。

该试用证明接口可以使用，也证明格式校验不能替代需求语义审查。指南补充相应例子不保证后续模型永不犯同类错误；没有宣称生成质量已全面通过。

## 本地 Ego 能力观察

使用 Ego 0.6.1.13、官方 Skill 2.1.0，只访问本轮 loopback 合成页，没有重跑 UAT。

- 重命名的页面结果和刷新读回一致；真实鼠标拖动的 pointer down/up 为 isTrusted，日期顺延两天并在刷新后保持。
- Network/Runtime 记录提供目标请求、响应、一个合成错误及指定响应正文。实际 13 个事件规范化为 5 个范围内摘要，正文只选取 4 个显式上下文字段；CLI 查询得到目标请求和合成 409 状态。8 个其他事件被省略，采集完整性仍为 unknown。
- 父页面与稳定派生页面均取得实际文件，分别 65 字节，与合成预期内容一致。
- target=_blank 直接打开附件的临时派生页，父页提前监听下载仍在 6 秒观察窗口内超时，没有取得文件。服务端 GET 不证明客户端下载完成；当前取证路径对此场景存在覆盖限制，根因未确认，未用 fetch 替代 UI 下载。
- 首次截图返回最小化错误；通过本任务 tabs 返回的真实 targetId 查询并恢复自有窗口后成功。错误和恢复记录均保留，没有操作原有用户窗口。

这些事实事后整理为一个 v5 能力报告：1 场景、7 目标、6 已验证、1 无法判断、0 缺评估，另保留首次截图失败的 attempt。明确标注 baseline 为事后整理，不冒充执行前冻结。三格式文件核验通过，Ego 实际打开后检查计数、混合结果、筛选和 22 个带 src 图片元素均成功解码，无横向溢出。最终仅澄清了“全部证据去重后内容”的计数文案，避免与截图数量混读；该文案后的另存报告做文件验证，未再次打开浏览器。

合成服务已停止，自有 TaskSpace finish 后独立读回消失，原有 Space 保留。原 UAT 目录 648 个已有文件的哈希与大小前后全部一致。

## 使用影响和限制

新工具只接受 v5，旧格式明确拒绝。历史自包含报告仍可查阅；新版不会读取旧 run，也不自动迁移。用户级已安装 Skill 未被替换，需要按新的完整候选包另行安装后才使用新行为。

只完成本机 Node 24 与本地合成能力验证，未重跑 Node 22、真实 UAT、多身份或后台巡检。协议字段白名单和显著凭据替换不保证全面脱敏；路径和选中字段值仍需审核。目标引用及哈希证明结构与留存字节，不能证明业务事实真实性或 AI 判断正确。followUpOf 是声明的关联，不自动认证外部运行或替换旧结论。
