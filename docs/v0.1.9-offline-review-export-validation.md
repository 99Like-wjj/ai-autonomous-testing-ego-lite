# v0.1.9 离线评审导出验证

日期：2026-11-03。离线导出实现及本轮工程自测完成，**Ego 的文件选择器保存、下载、阅读和恢复路径通过实际检查**。真实网站业务测试未执行；其他宿主验证范围见下文。

## 实现范围

- 浏览器与可选 CLI 共用纯评审文档生成器；默认 HTML 独立可读，内嵌完整 v9 反馈，可选 JSON 和完整数据复制。
- 文件选择器保存后关闭并逐字节读回；取消、写入错误和读回不一致不报成功，也不自动重试下载。下载路径只报告发起下载，实际文件另行核对。
- 删除审阅 HTTP 服务、CLI 启动命令及运行分发文件，离线页面没有请求服务的代码，CSP 的 connect-src 为 none。
- 更新当前 Skill 指南、中英文文档、语言文案、源码导航及测试；历史设计仅新增替代说明，历史正文保留。
- 当前主契约 v9 和 documentVersion 2 保持不变。没有生成候选安装包、替换用户已安装 Skill 或改写业务运行。
