# v0.1.7 报告可用性与证据事实设计

2026-10-29：维护者已审核完整设计并批准开发、自测，以及八主题切换。当前候选版本为 **0.1.7-rc.1 / report-usability-1**；不是正式发布。本文件是获批设计的仓库内通用说明，私有报告和截图不进入源码或发布包。

## 读者路径

报告按“场景总览 → 场景内测试点 → 目标事实与证据”组织。场景总览显示每个场景的目标总数、四态分布和记录缺口，不把场景推算成一个业务状态。全局和场景内搜索按目标匹配，保留场景分组、命中数、未命中目标的全量入口；零结果提供恢复操作。

目标详情先显示业务标题、原预期、实际与判断边界，再显示身份/对象/初态、实际动作与相邻证据、复现准备和缺口、来源与历史。计划不是实际执行；登记时间不是现场时间。未登记评估不属于四态，后续成功不掩盖首次异常。不同现象各自引用事实，不能由关键词推算独立缺陷数量。

## v6 事实与引用

- `goal.title` 在冻结时提供，原 `expected/basis/requiredRefs` 仍是权威约束。
- `record.contexts` 保存环境、身份、对象、初态、授权的有来源事实；每项可声明已知、未知或不适用，未知需说明原因。角色切换使用新上下文。
- `observations` 可保存 `contextId/actual/occurredAt/actions/evidenceLinks`。动作描述实际输入及读回，可引用原计划，但不从计划复制出虚假执行步骤。
- `assessments` 可提供摘要、多现象、结构化缺口、复现准备与修订关系。原四态与归因独立；复现准备不能证明已重复验证。
- `record.findings` 记录主题及关联理由，区分原范围与额外发现，保留提议/审核状态；不自动归并为独立bug。
- 证据元数据说明媒体类型、采集范围、页面/对象、用途、局限、上下文图、正文完整性和脱敏。工具检查引用和文件，不代替语义判断。

串行 `record` 与审核后的 worker import 写入同一事实账本。上下文、动作、现象、主题和图片关联全部映射并验证；保留不可变事实、幂等、并发修订冲突及恢复机制。禁止把局部图或HTTP成功扩张为无关目标通过。

## 证据与交付

图片保留原像素，用内容哈希去重存储、用证据ID保留不同登记及引用。正文按安全文本展示，区分完整、选取字段、摘要、截断、被排除、采集失败及未知。超过内嵌预算明确省略范围；需要完整交付时显式选择附件包。结构/引用损坏和哈希不匹配不能当作正常交付。

从已留存网络事件选择并导出证据时只读本地，不重新请求业务端点，保留来源、字段范围、正文状态和输出省略说明。缺少首次现场时写明缺口；后续补证不冒充首次现场。

HTML、JSON、Markdown使用同一已封存事实与统计口径。HTML禁止联网，任何源内容按数据处理。图片查看器支持适应、原尺寸、缩放、前后图及键盘关闭，打开/关闭保留位置和焦点；坏图与未交付正文给出具体提示。证据库区分当前、历史及未引用材料。

## 八主题设计

右上角“背景”按钮打开八个具名色板：暖砂灰、雾松绿、雾蓝灰、浅杏纸纹、深海蓝、石墨灰、墨松绿、暖炭棕。默认暖砂灰。颜色集中在主题配置和语义CSS变量，组件不散落八套分支；轻微纹理来自本地CSS，不加载远端背景图片。

切换只改变呈现，不能改事实JSON、统计、图像像素或证据哈希。不对截图应用暗色反相/滤镜。主题偏好仅在浏览器允许时本地保存；存储被禁用、值损坏或不支持时仍能即时切换并使用默认值，不阻断报告。键盘可操作，选中状态有文本和语义标记，颜色不是唯一状态信息。浅色/深色正文与边界都使用主题变量。

## 升级与验收边界

统一主契约升v6，networkVersion仍独立为1。旧v5运行不原地迁移，也不只改版本号；历史文件仍可用原工具独立打开。事后整理另建新资产并标明来源。源码候选包不自动安装到用户Skill目录。

验收分为结构/事务测试、真实浏览器展示矩阵、读者任务。至少验证混合状态筛选、场景层级、实际过程与正文、坏图/缺口、历史与关联、主题切换及存储失败、图片缩放/关闭返回、长报告导航和离线交付。合成样本须显式标记；代理自测不等于真实UAT、跨宿主业务验证或独立人员可用性验收。发布、合并、安装另依当次授权。
